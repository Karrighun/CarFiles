# CarFiles · 0.4.0

> 0.4.0: переработаны захват и транспорт кадров, новый интерфейс — см. [CHANGES-0.4.0](docs/CHANGES-0.4.0.md).

Технический прототип для локальных файлов, YouTube и захвата экрана. Android 11+, Kotlin/Java, Media3, SAF. Целевая связка пользователя: Samsung S24 FE + GAC GS8 2026, Android Auto по USB и без провода.

## Проверено в настоящем Android

31.10.2026 приложение установлено и запущено в официальном Android 15 AOSP ARM64 эмуляторе. Проверены главный экран, поиск YouTube и воспроизведение Big Buck Bunny, системное разрешение MediaProjection, получение JPEG по HTTP, обновление потока после перехода на главный экран Android, остановка захвата и закрытие endpoint. В журнале AndroidRuntime ошибок не обнаружено в ходе этих сценариев.

В панели разработки показывается настоящий экран эмулятора через ADB с обновлением примерно раз в секунду. Нажатия передаются в эмулятор. Настроена автоматическая пересборка и установка после правок исходников. Эта панель разработки и поток MediaProjection внутри приложения — два разных механизма.

Сборки обычного и экспериментального APK прошли `testDebugUnitTest lintDebug assembleDebug`: 5 unit-тестов успешны; lint — 0 ошибок, 24 предупреждения для обычного APK и 28 для Lab. Подписи обоих APK проверены. Эти результаты не подтверждают работу на реальной магнитоле.

## Функции

- Файловый браузер: выбор папки через SAF, сохранение доступа, вложенные папки.
- Фото и видео на телефоне; воспроизведение аудио через Media3 и стандартный Android Auto аудиокаталог.
- YouTube: встроенная мобильная веб-версия, поиск и проигрывание, обработка внешних ссылок, остановка при уходе с экрана. Это не интеграция YouTube Data API и не извлечение прямых потоков. Требуются интернет и рабочий Android System WebView.
- «Трансляция экрана»: системное согласие при запуске, foreground service, временный ключ доступа, JPEG-поток до 4 кадров/с, максимум 720 px по длинной стороне, остановка из приложения/уведомления. Передаётся изображение; звук и обратные касания не реализованы.

## Два APK

**Обычный**: package `dev.carfiles`, версия `0.2.0`. В Android Auto — аудиокаталог. YouTube и захват экрана проверены на Android-телефоне в эмуляторе, без вывода на автомобильный экран.

**CarFiles Lab**: package `dev.carfiles.lab`, версия `0.2.0-projection-lab`. Дополнительно подключён экспериментальный legacy-адаптер Android Auto: `CarActivityService`, экран YouTube и отображение кадров MediaProjection. APK установлен и запущен в эмуляторе, но автомобильный host в эмуляторе не установлен и адаптер им не вызван. Видимость и работа в Android Auto на S24 FE/GAC не подтверждены. См. [описание адаптера](docs/PROJECTION-LAB.md).

Можно установить обе версии рядом; выбранные папки и настройки у них раздельные.

## Сборка

Нужны JDK 17, SDK Platform 35 и Build Tools 35.0.0. Gradle Wrapper 8.11.1 включён.

1. Открыть проект в Android Studio или указать `sdk.dir=/absolute/path/to/sdk` в `local.properties`.
2. Обычный APK: `./gradlew testDebugUnitTest lintDebug assembleDebug`.
3. Экспериментальный APK: `./gradlew -PprojectionLab=true testDebugUnitTest lintDebug assembleDebug`.
4. Оба варианта записываются в `app/build/outputs/apk/debug/app-debug.apk`; сохранить результат перед сборкой другого варианта.
5. Установка: `adb install -r app/build/outputs/apk/debug/app-debug.apk`.

GitHub Actions проверяет обычную сборку при размещении этого проекта в корне репозитория. В GitHub Actions workflow ещё не запускался.

## Что ещё предстоит

- Проверить Android Auto projection host на реальном S24 FE/GAC; доступность старого SDK и канала установки — отдельный риск.
- Увеличить частоту/качество трансляции через аппаратное кодирование, добавить аудио и транспорт с контролем задержек. JPEG/HTTP без TLS — текущий отладочный транспорт по адресу с временным ключом, не готовый публичный сервис.
- Проверить передачу кадров между процессами автомобильного host: Lab сейчас читает кадры из памяти процесса приложения.
- Для беспроводного Android Auto адрес локальной сети может быть недоступен внешнему устройству. Доступность LAN-потока не доказывает доступность его на магнитоле.
- Проверить вход в YouTube/внешние аккаунты, fullscreen на разных экранах и сетевые ошибки. Защищённые окна могут не захватываться средствами Android.
- Room-индекс, инкрементальное обновление библиотеки, очередь, постоянная история и позиции, уведомление автомобиля об изменениях.
- Просмотр PDF/Office/текста, IPTV, субтитры и расширенные форматы пока отсутствуют. Декодирование зависит от устройства.
- Сертификация и распространение через Google Play не выполнены.

Аудиокаталог пока плоский, сканируется при запросах, ограничен 10000 объектов и глубиной 32. Для первого теста выбирать небольшую локальную папку. Файлы не копируются и не удаляются.
