# 0.5.0 — вывод на Android Auto через Car App Library

**Диагноз по фото и журналу тестировщика (AA 17.9.664044, Android 17, GAC GS8):** в машине открывался стандартный
аудио-браузер (название файла + поиск). В журнале не было ни одной записи от старого aauto-сервиса — Android Auto его
больше не вызывает. Путь через `CarActivityService` убран полностью (вместе с `aauto.aar`, Lab-сборкой).

**Новый путь:** `CarAppService` + `NavigationTemplate` + `SurfaceCallback`. Host выдаёт `Surface` на весь экран, приложение
рисует на ней последний кадр трансляции (Canvas; запасной путь — VirtualDisplay + Presentation). Учитывается видимая область.
Категория: «Навигация» (по умолчанию) или «Погода» (не занимает слот навигации) — переключатель на экране «Трансляция».
Уведомление «Машина подключена» запускает трансляцию одним касанием. Журнал: сервис → сессия → поверхность → кадр.

Не реализовано: касания с экрана машины, звук трансляции. Единственный APK `dev.carfiles` (без `.lab`).
