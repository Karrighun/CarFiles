## Живая разработка

Локальная панель этого чата получает реальные PNG из ADB примерно раз в секунду; нажатия передаются в тестовый эмулятор. Отдельный watcher отслеживает исходники основного приложения, пересобирает APK, устанавливает его и перезапускает MainActivity. При ошибке сборки остаётся предыдущий APK. При обновлении приложения новый сеанс захвата требует нового системного разрешения.

Панель работает, пока запущены локальные процессы эмулятора и сервера; это инструмент разработки, не экран Android Auto. Сохранённые скриншоты — реальные кадры APK и MediaProjection, не макеты.

Автопересборка проверена отдельно: watcher заметил изменение времени исходника, выполнил assembleDebug (успешно), затем adb install и запуск MainActivity. Журнал сохранён в CarFiles-checks/0.2.0/live-rebuild.log.
